# Public repository safety and source access

**This repository is PUBLIC.**

1. Never commit organizational source code, Git mirrors, private Azure DevOps exports, unapproved business documents, work item dumps, real production/customer data, secrets, tokens, connection strings, or proprietary runtime metadata here.
2. Store only general educational material and already-approved, non-sensitive knowledge.
3. Keep current source analysis in an organization-controlled private repository or access Azure DevOps with an authorized read-only connection.
4. Before mirroring any corporate repository: require organization approval, select an approved private destination, limit access, scan secrets and licenses, preserve branch/commit provenance, and configure safe synchronization. Check [Issue #10](../../issues/10).
5. Public roadmap issues intentionally avoid internal work item details. For confidential findings keep only a generic topic and refer to secured source out-of-band.
6. Do not treat a GitHub account owner's admin permission on this public repository as approval to redistribute code owned by another organization.

No source mirroring has been performed as part of the roadmap initialization.
